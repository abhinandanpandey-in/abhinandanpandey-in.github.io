# Project case study template

## Problem
State the concrete problem and threat model.

## Implementation
Describe architecture, trust boundaries, dependencies and design decisions.

## Evidence
Link source, tests, fixtures, CI runs and reproducible commands. Include numbers only when backed by raw results.

## Security tests
List positive, negative, boundary, malformed-input and adversarial tests.

## Limitations
State what the project does not protect against and what has not been tested.

## Reproduction
Provide exact setup/execution commands, versions and expected outcomes.
